# Compute Guild

## 1. What belongs here

On-robot and infrastructure compute, control, safety-control, networking, and wireless communication components.

## 2. Component Classes

| Class | Code | Folder | Cards |
|---|---|---|---:|
| Edge AI Module | EAM | `edge_ai_module` | 0 |
| Industrial PC | IPC | `industrial_pc` | 0 |
| MCU/Controller | MCU | `mcu_controller` | 0 |
| Safety Controller/PLC | SPL | `safety_controller` | 0 |
| GPU Server | GPU | `gpu_server` | 0 |
| Network Equipment | NET | `network_equipment` | 0 |
| Wireless Communication | WLS | `wireless_communication` | 0 |

## 3. What information we need

- Official product page
- Datasheet
- Manual
- Mechanical drawing (PDF/DXF)
- 3D CAD (STEP/IGES)
- Interfaces
- Power characteristics
- Thermal information
- Environmental rating
- SDK
- ROS2 compatibility

## 4. How to contribute

Issue or Pull Request → Richard review → merge.

See `../../CONTRIBUTING.md`.

## 5. Evidence and redistribution

Public source URLs are required for specifications.

Default policy is link-only.

Files may be stored only when redistribution is explicitly allowed.

Do not upload purchased, NDA, Hills Robotics,
or other company-provided files.

# Manipulation Guild

## 1. What belongs here

Robot arms, joint actuation, grasping, hands, end-effectors, and tool-changing components.

## 2. Component Classes

| Class | Code | Folder | Cards |
|---|---|---|---:|
| Robot Arm | ARM | `robot_arm` | 0 |
| Joint Actuator Module | JAM | `joint_actuator_module` | 0 |
| Gripper | GRP | `gripper` | 0 |
| Dexterous Hand | HND | `dexterous_hand` | 0 |
| End-Effector Tool | EET | `end_effector_tool` | 0 |
| Tool Changer | TCH | `tool_changer` | 0 |

## 3. What information we need

- Official product page
- Datasheet
- Manual
- Mechanical drawing (PDF/DXF)
- 3D CAD (STEP/IGES)
- Interfaces
- Power characteristics
- Thermal information
- Environmental rating
- SDK
- ROS2 compatibility

## 4. How to contribute

Issue or Pull Request → Richard review → merge.

See `../../CONTRIBUTING.md`.

## 5. Evidence and redistribution

Public source URLs are required for specifications.

Default policy is link-only.

Files may be stored only when redistribution is explicitly allowed.

Do not upload purchased, NDA, Hills Robotics,
or other company-provided files.

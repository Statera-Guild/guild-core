# Driving Guild

## 1. What belongs here

Drive, steering, braking, rolling, and suspension components used to create robot mobility.

## 2. Component Classes

| Class | Code | Folder | Cards |
|---|---|---|---:|
| Drive Module | DMD | `drive_module` | 0 |
| Electric Motor | MOT | `electric_motor` | 0 |
| Gearbox/Reducer | RED | `gearbox_reducer` | 0 |
| Motor Driver | MDR | `motor_driver` | 0 |
| Wheel | WHL | `wheel` | 0 |
| Caster | CST | `caster` | 0 |
| Steering Module | STR | `steering_module` | 0 |
| Brake | BRK | `brake` | 0 |
| Suspension | SUS | `suspension` | 0 |

## 3. What information we need

- Official product page
- Datasheet
- Manual
- Mechanical drawing (PDF/DXF)
- 3D CAD (STEP/IGES)
- Interfaces
- Power characteristics
- Thermal information
- Environmental rating
- SDK
- ROS2 compatibility

## 4. How to contribute

Issue or Pull Request → Richard review → merge.

See `../../CONTRIBUTING.md`.

## 5. Evidence and redistribution

Public source URLs are required for specifications.

Default policy is link-only.

Files may be stored only when redistribution is explicitly allowed.

Do not upload purchased, NDA, Hills Robotics,
or other company-provided files.
